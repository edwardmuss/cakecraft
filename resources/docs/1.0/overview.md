## Overview

Our API allows you to send and receive SMS messages across mobile service providers in Kenya 🇰🇪.

The SMS API uses `HTTP` verbs and a `RESTful` endpoint structure.

Request and response payloads are formatted as JSON using UTF-8 encoding and URL encoded values.

All endpoints are protected by OAuth v2 and thus require an access token.
Your requests should typically contain a header element specifying data type , together with the Bearer access token.
