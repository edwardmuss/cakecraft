```php
https://rebuetext.com/api/v1
```

<a name="balance"></a>

## Check Account Balance

| Method | URI                |
| :----- | :----------------- |
| GET    | `/account/balance` |

> {info} Remember to always include the Request header. See how [HERE](/{{route}}/{{version}}/authentication)

## Sample Success Response

StatusCode `200`

Content

```json
{
    "status": true,
    "data": {
        "balance_kes": 1958.04,
        "balance_minor": 195804,
        "date": "2026-03-03 18:34:21"
    }
}
```

<a name="top-up"></a>

## Top Up

| Method | URI               |
| :----- | :---------------- |
| POST   | `/account/top-up` |

## Request Params

| Param           | Type               | Description                                      |
| :-------------- | :----------------- | :----------------------------------------------- |
| amount          | `float`(required)  | Amount to top up a new account                   |
| branch_id       | `string`(required) | Account Id of sub account to be topped up        |
| topup_reference | `string`(optional) | Top up Reference string generated by your system |

### Sample Request Body

```json
{
    "amount": 1500.0, // in KES
    "branch_id": 4, // subaccount id
    "topup_reference": null
}
```

<a name="fail-res"></a>

## Sample Fail Response

StatusCode `403`
Reason `Forbidden. Access to the resource is prohibited`

Content

```json
{
    "status": false,
    "message": "The account is not a subaccount of the parent account."
}
```

```json
{
    "status": false,
    "message": {
        "branch_id": ["The selected account id is invalid."]
    }
}
```

> {info} Official SDKs can be obtained <a href='https://github.com/cloudrebue/PHP-BULK-SDK' target="__blank"> HERE</a>. Also consider having a look at our responses format HERE In order to anticipate all the formats our responses are returned in, and hence a better handling of the same.
